## RUMUS EXCEL PENTING

### STATUS Otomatis (Kolom AC):
```
=IF($C4="","",IF($AB4="","PROSES","SELESAI"))
```

### Folder Laporan Hyperlink (Kolom AE):
```
=HYPERLINK("file:///path/to/folder","[Buka X file]")
```

### COUNTIFS untuk Ringkasan Per Tahun:
```
=COUNTIFS('Data R1'!$C$4:$C$1001,"<>",'Data R1'!$AD$4:$AD$1001,$A25)
+COUNTIFS('Data R2'!$C$4:$C$1001,"<>",'Data R2'!$AD$4:$AD$1001,$A25)
+... (untuk semua sheet)
```

### % Selesai per Regional:
```
=IF(COUNTA('Data R1'!$C$4:$C$1001)=0,0,
  ROUND(COUNTIF('Data R1'!$AB$4:$AB$1001,"<>")/COUNTA('Data R1'!$C$4:$C$1001)*100,0))
```
